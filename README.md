# 🍽️ Restaurant Landing Page

This repository contains a restaurant landing page created as a frontend practice project using HTML and CSS.

## 📌 About the Project
This project was built to practice webpage structuring, styling, and responsive UI design by taking inspiration from existing restaurant website templates.

## 🎯 Objective
- Practice HTML and CSS skills  
- Learn modern webpage layout design  
- Improve frontend development basics  
- Understand responsive design concepts  

## 🛠️ Tech Stack
- HTML5  
- CSS3  

## ✨ Features
- Modern restaurant-style UI  
- Clean homepage layout  
- Attractive sections for menu and offers  
- Beginner-friendly project structure
